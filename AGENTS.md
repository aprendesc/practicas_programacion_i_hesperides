# Hespérides — Programación I practice

## Purpose and context

This repository provides student notebooks for Programación I at Universidad de las Hespérides. The [academic corpus](/Users/alejandroprendes/Desktop/projects/hesperides/AGENTS.md) holds the subject notes and teaching context.

## Repository map

- [practicas/](practicas/): student exercises grouped by chapter.
- [examenes/](examenes/): examination material.
- `profesor/`: local teacher preparation and solutions.
- [requirements.txt](requirements.txt): notebook dependencies; [README.md](README.md): installation and notebook guidance.
- `context/issues/` and `context/sessions/`: contribution records and meeting summaries.
- [.githooks/CLONE.md](.githooks/CLONE.md): local clone safeguards and setup.

## Methodologies and references

Choose contracts by the issue's main purpose, not by supporting scripts. Use [coding-contract-guidelines](/Users/alejandroprendes/.codex/skills/coding-contract-guidelines/SKILL.md) for software implementation, [documental-contract-guidelines](/Users/alejandroprendes/.codex/skills/documental-contract-guidelines/SKILL.md) for authored documents, and [general-contract-guidelines](/Users/alejandroprendes/.codex/skills/general-contract-guidelines/SKILL.md) for organization, administration and class preparation, recording, delivery or review without a principal manuscript. Each contract lives in `context/issues/<issue>/`; documentary prose and figures belong inside that issue. Preserve requirements, decisions, pauses and historical evidence. Real supporting validators may stay beside any task without turning it into a software feature. Global functional scenarios remain in `context/tests/`.

Apply [development-methodology](/Users/alejandroprendes/.codex/skills/development-methodology/SKILL.md). Preserve student notebook edits and keep teacher solutions separate from the student edition. Publication follows the user's explicit instructions.
